# Reproduction

## Environment

The archived revision results were produced with R 4.5.3 on Windows.
Exact observed package versions are in `environment/package_versions.csv`;
the revision session is recorded separately. Python 3 with its standard
library is sufficient to run `verify_release.py`.

Required R packages:

```r
install.packages(c(
  "readxl", "dplyr", "tidyr", "stringr", "lubridate", "forcats", "purrr",
  "tibble", "openxlsx", "ggplot2", "patchwork", "cowplot", "scales",
  "emmeans", "car", "lme4", "lmerTest", "broom", "broom.mixed", "quantreg",
  "sandwich", "lmtest", "mgcv", "scatterplot3d", "svglite", "ragg",
  "ggrepel", "multcompView"
))
```

Package versions can affect optimizer and quantile-regression results.
For exact comparisons, use the recorded versions. Arial is used in the figure
code; replacing unavailable fonts can change appearance without changing data.

## Execution Order

1. Reconstruct and compare the processed cohort from the raw Excel export.
2. Fit the primary LMM and logistic mixed models and generate the original
   exploratory source data.
3. Fit the final alternative thresholds, complete-year, 25-65 kg and
   ancestry-adjusted models.
4. Refit the two P5/P95 models and sire-subset baseline upper-tail model using
   nine-point adaptive quadrature and a second optimizer.
5. Refresh final estimates and run the 999-replicate bootstrap. Each replicate
   uses seed `20261005 + replicate_number`; all observations from each sampled
   dam are included together. Warned replicates are checked using the
   Barrodale-Roberts algorithm and objective values.
6. Compare key final result files with `expected_results/revision/`.

The revision analysis uses saved fits if they exist. No binary model caches are
shipped in this release. A fresh extraction therefore fits the models from data.
Subsequent runs can reuse locally generated caches. To force a fresh model run,
use a fresh extraction rather than deleting files from an active working copy.

`original_analysis/outputs/` includes legacy intermediate analyses needed by
the original plotting code. These are not all primary manuscript analyses.
The final statistical results are the revision outputs, with reference values
in `expected_results/revision/`.

## Outputs and Figures

Recomputed results are written to `revision_analysis/results/`.
Figure 3 is rebuilt in `reproduced_figures/` from revised estimates. Figures
1, 2 and 4 in that folder are the retained manuscript images. Figure 1 is an
illustrative workflow, not a statistical output; its raster is supplied rather
than generated from data. Original Figures 2 and 4 can also be regenerated by
the original plotting scripts, but rendering may differ across fonts/platforms.
The supplied `figures/` files are the publication reference images.

The two XLSX files are fixed presentation exports. Their underlying numerical
sources are supplied as CSVs; the public pipeline does not rerun the private
document-generation or submission-packaging helpers.

## Verification Scope

File hashes, Excel cell preservation, PNG pixel preservation and raw-to-cohort
reconstruction are release checks. The final model source and numerical
references are supplied for independent rerunning. Packaging alone is not
evidence that every model has been freshly refitted on a different machine.
